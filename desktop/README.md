# 音栖 Windows 0.1.0

Windows 10/11 x64 桌面播放器，通过 Wi-Fi 读取音栖 Android 0.15.3 及以上版本的作品库。

## 连接

1. 手机和电脑连接同一个 Wi-Fi。在手机音栖的“设置 → 电脑连接”中开启局域网共享。
2. 启动 `releases/Yinqi-win32-x64/Yinqi.exe`，点击“连接手机”。
3. 输入手机显示的地址和六位配对码。地址可填 `192.168.1.8:17856` 或完整的 `http://192.168.1.8:17856`。
4. 配对成功后浏览并播放。配对码五分钟过期，可在手机刷新；已配对的电脑不受配对码刷新影响。停止共享会撤销当前配对，下次需要重新配对。

需保留 Windows 程序目录中的全部文件。手机进入其他 Wi-Fi 或 IP 改变时共享会停止，请重新开启并在电脑配对。访客网络、路由器客户端隔离或 VPN 可能阻断设备互访。

## 使用

- 手机是唯一作品库，桌面端不扫描本地音频、不下载整套音频文件、不请求 DLsite 或 DeepSeek。
- 作品名、译名、社团、声优、封面、收藏、目录及曲目来自手机。桌面可手动编辑作品原名、社团及声优并写回手机。库更新约五秒内刷新，也可手动刷新。
- 音频在电脑解码并从电脑默认音频设备输出。支持 Chromium 支持的 WAV、MP3、FLAC 等音频，实际支持情况取决于文件编码。手机只提供文件，不会同步发声。
- 搜索、目录切换、社团/声优/收藏筛选、六种排序、当前作品定位、同文件夹默认队列、手动队列、拖动排序、批量添加、播放倍速、睡眠定时、同名 LRC 字幕、封面背景与背景调节。
- 队列右键菜单可编辑。字幕点击跳转且保持浏览位置，右下角定位按钮恢复跟随。
- 空格播放/暂停，左右方向键前后跳十五秒。
- 收藏、收听位置、字幕外观设置写回手机。Windows 队列及播放位置也保存到手机，重连后恢复为暂停状态。
- 手机播放器与电脑播放器各自播放，队列独立。同一曲目同时在两端收听时，位置采用最后写入的数据。

## 构建

Node.js 24+。运行 `npm ci`。Electron 45 的本地开发运行时可使用 `node node_modules/electron/install.js` 安装。运行 `npm start` 启动开发版。

`build-desktop.ps1` 从本机已校验的 Electron ZIP 缓存打包 Windows x64 版本，不需要管理员权限。运行时的许可证及第三方声明保留在发布目录。
